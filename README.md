# Викторина «А.С. Пушкин»

Интерактивная викторина на HTML5, CSS3 и JavaScript, посвящённая жизни и творчеству Александра Сергеевича Пушкина.

## Возможности

- 35 вопросов трёх типов:
  - **Один вариант** (20 вопросов) — выбор из 4 вариантов
  - **Несколько вариантов** (10 вопросов) — выбор из 5 вариантов, несколько правильных
  - **Свой ответ** (5 вопросов) — свободный ввод
- Мгновенная проверка с подсветкой правильного/неверного ответа
- Пояснение к каждому вопросу
- Прогресс-бар и счётчик вопросов
- Финальный экран: результат в процентах, количество верных ответов, звание
- Система званий: Новичок → Любознательный → Читатель → Знаток → Эксперт → Настоящий пушкиновед
- Адаптивный дизайн (мобильные устройства + ПК)
- Оформление в стиле литературы XIX века

## Запуск

Откройте `index.html` в любом современном браузере. Для корректной работы с относительными путями рекомендуется использовать локальный сервер:

```bash
python3 -m http.server 8080
# или
npx serve .
```

## Источники данных

Все вопросы взяты из файла `info.txt`.

## Технологии

- HTML5
- CSS3 (Flexbox, анимации, медиа-запросы)
- JavaScript (vanilla JS, без библиотек)
